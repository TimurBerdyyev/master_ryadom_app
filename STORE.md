# Публикация в Google Play — всё для Play Console

Файлы для загрузки — в папке `store/`, сборка — в GitHub Releases (`master-ryadom.aab`).

## 0. Перед началом

1. Аккаунт разработчика: https://play.google.com/console — разовый взнос $25, проверка личности (паспорт) — до нескольких дней.
2. **Ключ подписи — важно.** При создании приложения Play спросит про «Подписание приложений в Google Play».
   Выберите **использовать свой ключ** (Use existing app signing key / Export and upload a key from Java keystore)
   и загрузите ключ из `~/master-ryadom-keys/release.p12` (Play даёт инструкцию и утилиту PEPK).
   Тогда APK с сайта и версия из Google Play будут подписаны одним ключом и смогут обновлять друг друга.
   Если оставить ключ, сгенерированный Google, приложение из Play не встанет поверх APK с сайта —
   пользователям придётся удалить старое.
3. Сборка: GitHub → репозиторий master_ryadom_app → Releases → последняя версия → `master-ryadom.aab`.
   Новая сборка создаётся сама при каждой загрузке изменений в репозиторий (номер версии растёт автоматически).

## 4. Доступ к приложению (для проверяющих Google)

Часть функций (кабинет мастера) доступна после входа. В разделе **App access** выберите «Часть функций ограничена»
и укажите тестовый аккаунт мастера: создайте его на сайте (регистрация мастера), отметьте «Проверен» в админке
и впишите телефон и пароль с инструкцией: «Войдите через “Для мастеров” → “Войти”». Клиентская часть работает без входа.

## 5. Реклама, аудитория, рейтинг

- **Реклама:** нет.
- **Целевая аудитория:** 18 лет и старше (сервис не для детей).
- **Возрастной рейтинг (анкета):** насилия, азартных игр и т. п. нет; **пользователи могут общаться друг с другом
  (чат) и делиться фото** — ответить «да». Пользователи обмениваются номерами телефонов — «да».
  Ожидаемый рейтинг: 12+ / Teen (из-за общения между пользователями).
- **Новостное приложение:** нет. **Приложение для правительства / здоровья / финансов:** нет.

## 6. Безопасность данных (Data safety)

Шифрование при передаче: **да** (HTTPS). Пользователи могут запросить удаление: **да** (ссылка выше).
Данные не продаются и не передаются для рекламы.

| Тип данных | Собирается | Передаётся третьим лицам | Зачем | Обязательно? |
|---|---|---|---|---|
| Имя | да | нет* | Работа приложения, связь | да |
| Номер телефона | да | нет* | Работа приложения, связь | да |
| Email (мастера) | да | нет | Аккаунт, уведомления | да для мастеров |
| Точное местоположение (мастера) | да | нет | Показ на карте клиентам | нет (по желанию) |
| Фото | да | нет* | Работа приложения | нет |
| Сообщения в приложении (чат) | да | нет* | Работа приложения | нет |
| Другой пользовательский контент (текст заявок, отзывы) | да | нет* | Работа приложения | да |
| Идентификаторы устройства (push-токен) | да | нет | Уведомления | нет |

\* Данные видят другие пользователи сервиса по смыслу работы (клиент — выбранный мастер и наоборот); это не «передача
третьим лицам» в терминах Google. Подрядчики (хостинг Render, почта Brevo, Firebase) — обработчики данных.

## 7. Разрешения и их объяснение

- **Уведомления** (`POST_NOTIFICATIONS`) — новые заказы, предложения и сообщения.
- **Местоположение** (`ACCESS_FINE/COARSE_LOCATION`, только когда приложение открыто) — мастер по желанию показывает
  себя на карте клиентам. Фонового доступа нет, поэтому декларация о фоновом местоположении **не нужна**.
- **Интернет** — работа приложения.

## 8. Выпуск

1. Сначала **Внутреннее тестирование** (Internal testing): загрузите `master-ryadom.aab`, добавьте тестеров по email —
   выпуск доступен почти сразу, без полной проверки.
2. Для **рабочей версии** (Production) новые личные аккаунты разработчиков Google обязывают провести **закрытое
   тестирование с 12+ тестерами в течение 14 дней** — запланируйте это.
3. Риск: Google отклоняет приложения, которые «просто показывают сайт». У нас есть свои функции приложения
   (push-уведомления, карта с местоположением, нижние вкладки, офлайн-экран) — при отказе укажите это в апелляции.
